# Trackpad Dump Tool

改良版のCGEventダンプツールです。ネイティブのトラックパッドイベントがどのようなフィールドを持っているかを詳細に観測できます。

## 使い方

```bash
./dump
```

## 観測できる内容

- **左/右クリック**: 座標情報
- **2本指スクロール**: デルタ値とフェーズ情報
- **3-4本指ジェスチャー**: 全フィールド情報
  - type (29/30/31)
  - phase (MayBegin/Began/Changed/Ended/Cancelled)
  - subtype
  - mask (Thumbビットなど)
  - flags
  - デルタ値 (Δx, Δy)

## 重要な観測ポイント

ネイティブトラックパッドのジェスチャーを正確にエミュレートするには以下を確認：

1. **subtype=2**: ジェスチャーイベントの識別子
2. **maskにThumbビット(0x8)**: 親指を含む4本指ジェスチャー
3. **Beganフェーズ**: デルタ値は(0, 0)
4. **Endフェーズ**: Annotatedフラグ付き

## 権限設定

初回実行時は「システム設定 › プライバシーとセキュリティ › アクセシビリティ」での許可が必要です。
